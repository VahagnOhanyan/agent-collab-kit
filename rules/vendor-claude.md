# Адаптер вендора: Claude Code

Нужен ведущей сессии другого хоста (например Codex), когда в составе есть Claude Code.
Ставится, только если на машине есть `claude`. Какие роли Claude держит у конкретного
человека, какие модели по умолчанию и какие у него лимиты — в его личных правилах и составе
(`rules/personal.md`, `collab setup`), не здесь.

## Вызов без интерактива

`claude -p "<промпт>" --model <алиас или id> --permission-mode <режим> --output-format text|json </dev/null`, в фоне.

- `--model` — всегда явно, из `collab models` под нужный уровень: умолчание CLI — модель
  аккаунта, часто самая дорогая.
- Только чтение (ревью, разведка): `--permission-mode plan` или `--disallowedTools Edit Write`.
  Писать Claude может только там, где владелец разрешил, и по правилам записи проекта.
- `</dev/null` всегда: вызов в фоне без него может ждать ввода.
- Флаги сверять с `claude --help` установленной версии, а не с памятью.
- MCP-журнал `collab` Claude видит как `claude` (регистрация инсталлятора); ревью по роли он
  находит через `get_messages` / `submit_review`.
