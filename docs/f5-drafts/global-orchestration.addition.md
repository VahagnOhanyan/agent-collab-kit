## Машинный набор (`~/agent-kit`)

После `agent-kit-install` в любом проекте этой машины доступны: журнал `collab` (задачи, ревью по роли, решения, одобрения владельца) — но только когда в проекте выполнен явный `collab init`, сам он не заводится; скиллы `/codex-review` и `/ui-review`; субагенты `implementer` и `verifier`. Всё уровня пользователя — общий код для всех проектов, конфиг и раннеры каждого проекта — доверенный реестр `~/agent-kit/projects/<id>/`, вне самого репозитория.

`implementer` не пишет в дерево проекта, пока в его записи реестра нет `scopes.json` (`allow`/`deny`) — без файла запись запрещена по умолчанию, это осознанная граница, а не недосмотр.

Подключить новый проект: запись `project.json` (и `scopes.json`, если нужна запись) в `~/agent-kit/projects/<id>/` → `bin/agent-kit-install` → один раз `collab init` в корне проекта. Полный список команд и файлов реестра — `~/agent-kit/README.md`.
