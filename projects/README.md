# Доверенные реестры проектов

Каждый подключённый проект — свой каталог `<id>/` здесь. `.gitignore` в корне
набора исключает всё в `projects/`, кроме этого файла: реестр содержит
абсолютные пути, продуктовые детали и политику конкретного проекта, ничего
из этого не принадлежит истории самого инструмента.

Как подключить свой проект — раздел «Подключить проект» в `README.md` корня
набора.
