# Старое место реестра проектов

Реестр подключённых проектов живёт в `~/.agent-kit/projects/<id>/` и заводится командой
`collab connect` в папке проекта — см. «Подключить проект» в `README.md` корня набора.

Этот каталог — прежнее место: пока постоянного реестра на машине нет, установщик переносит
отсюда записи в релиз, а первый `collab connect` забирает их в постоянный реестр.
`.gitignore` набора исключает всё здесь, кроме этого файла.
